# Labfitnesstracker
 I made a simple program that helps track a running workout. The user can enter the type of workout, how long they worked out and the distance they ran.
The program also calculate how many calories you burned by multiplying the distance by 60.
In this project I used inheritance with a parent class called Workout and a child class called RunningWorkout. I also used Scanner to get information from the user. This project helped me understand better how inheritance and classes work in Java.
